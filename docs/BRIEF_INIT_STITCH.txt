2. MODULARISASI KOMPONEN PURE HTML & INKLUSI SCRIPT WAJIB
================================================================================
Karena website dibuat murni HTML (tanpa server-side include PHP `<?php include ... ?>`), terapkan sistem Component Loader Vanilla JS yang ringan, andal, dan modular:

1. **Ekstraksi Komponen ke `components/`**:
   - Pisahkan bagian `<header>`, `<nav>`, `<footer>`, dan `<aside>` (sidebar dashboard) dari file Stitch ke file masing-masing di folder `components/`.
   - Bersihkan tag pembungkus ganda agar komponen siap di-inject.

2. **Placeholder Tag & Inklusi Script Wajib di Halaman HTML**:
   Pada setiap file HTML (baik di `landing/`, `dashboard/`, `login.html`, maupun `index.html`), gunakan struktur tag dan script standar berikut:
   ```html
   <!-- Header & Navigasi -->
   <div data-component="header"></div>
   <div data-component="navbar"></div>

   <!-- Konten Utama Halaman -->
   <main>
     ...
   </main>

   <!-- Footer -->
   <div data-component="footer"></div>

   <!-- Script Wajib & Loader -->
   <script src="/assets/js/security-warning.js"></script>
   <script src="/assets/js/components.js"></script>
   <script src="/assets/js/main.js"></script>
   ```

   > **⚠️ CATATAN WAJIB KEAMANAN:**
   > File `/assets/js/security-warning.js` **WAJIB di-include** pada:
   > 1. Seluruh halaman Landing / Publik (`landing/*.html`)
   > 2. Halaman Login / Registrasi / Auth (`login.html` / `landing/login.html`)
   > 3. Seluruh halaman Dashboard / Admin (`dashboard/*.html`)
   > 4. Halaman Root (`index.html`)

3. **Engine Loader Komponen & Deteksi Menu Aktif Dinamis (`assets/js/components.js`)**:
   Implementasikan script loader mandiri yang secara otomatis mengaktifkan menu yang sesuai dengan URL halaman saat ini:
   ```javascript
   document.addEventListener("DOMContentLoaded", async () => {
     // 1. Muat seluruh komponen HTML secara asinkron
     const componentElements = document.querySelectorAll("[data-component]");
     for (const el of componentElements) {
       const name = el.getAttribute("data-component");
       try {
         const res = await fetch(`/components/${name}.html`);
         if (!res.ok) throw new Error(`HTTP error! status: ${res.status}`);
         const html = await res.text();
         el.innerHTML = html;
       } catch (err) {
         console.error(`Gagal memuat komponen: ${name}`, err);
       }
     }

     // 2. DETEKSI MENU AKTIF DINAMIS (Navbar Desktop, Mobile Drawer, Sidebar Dashboard)
     const currentPath = window.location.pathname.replace(/\/$/, "") || "/";

     const navContainers = document.querySelectorAll("nav, aside, #mobile-menu, [data-sidebar]");
     navContainers.forEach((container) => {
       // Ambil active classes custom dari atribut data-active-classes (jika ada di Stitch)
       const activeClasses = (container.getAttribute("data-active-classes") || "text-primary font-bold underline decoration-2 underline-offset-8").split(" ");
       const inactiveClasses = (container.getAttribute("data-inactive-classes") || "text-on-surface-variant opacity-80").split(" ");

       const links = container.querySelectorAll("a[href]");
       links.forEach((link) => {
         const href = link.getAttribute("href").replace(/\/$/, "") || "/";
         const isHome = (currentPath === "/" || currentPath === "/landing" || currentPath.endsWith("/index.html")) && (href === "/" || href === "/landing");
         const isMatchingPage = href !== "/" && (currentPath === href || currentPath.startsWith(href + "/"));

         if (isHome || isMatchingPage) {
           link.setAttribute("aria-current", "page");
           activeClasses.forEach(cls => cls && link.classList.add(cls));
           inactiveClasses.forEach(cls => cls && link.classList.remove(cls));
         } else {
           link.removeAttribute("aria-current");
           activeClasses.forEach(cls => cls && link.classList.remove(cls));
           inactiveClasses.forEach(cls => cls && link.classList.add(cls));
         }
       });
     });

     // 3. Inisialisasi event interaktif Mobile Menu (Hamburger Drawer)
     const mobileBtn = document.querySelector("#mobile-menu-btn");
     const mobileMenu = document.querySelector("#mobile-menu");
     if (mobileBtn && mobileMenu) {
       mobileBtn.addEventListener("click", () => {
         mobileMenu.classList.toggle("hidden");
       });
     }
   });
   ```

3. PERBAIKAN NAVIGASI & CLEAN URL (LINK TANPA `.html`)
================================================================================
Perbaiki seluruh atribut link yang diexport dari Stitch:
1. Ubah semua `href="#"` atau `data-path="..."` menjadi URL bersih:
   - Link Beranda: `href="/"` atau `href="/landing"`
   - Link Tentang: `href="/tentang"`
   - Link Program: `href="/program"`
   - Link Katalog: `href="/katalog"`
   - Link Donasi / Aksi: `href="/donasi"`
   - Link Kontak: `href="/kontak"`
   - Link Login: `href="/login"`
   - Link Dashboard: `href="/dashboard"`
   - Link Modul Dashboard: `href="/dashboard/anggota"`, `href="/dashboard/koleksi"`, dll.
2. Pastikan tombol Hamburger Mobile Menu berfungsi penuh (buka/tutup drawer mobile saat diklik).
3. Pastikan link navigasi internal (anchor `#section-id`) melakukan smooth-scroll ke elemen yang dituju.

4. KONFIGURASI `.htaccess` (APACHE / LARAGON / XAMPP / CPANEL)
================================================================================
Tulis file `.htaccess` di root folder dengan konfigurasi lengkap:
```apache
Options -Indexes
RewriteEngine On

# 1. Redirect URL berakhiran .html ke Clean URL (tanpa .html)
RewriteCond %{THE_REQUEST} \s/+(.+?)\.html[\s?] [NC]
RewriteRule ^ /%1 [R=301,L]

# 2. Routing Root '/' ke Landing Page
RewriteRule ^$ landing/index.html [L]

# 3. Routing Area Dashboard (/dashboard atau /dashboard/xxx)
RewriteCond %{REQUEST_FILENAME} !-d
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{DOCUMENT_ROOT}/dashboard/$1.html -f
RewriteRule ^dashboard/(.*)$ dashboard/$1.html [L]

# 4. Routing Area Landing (/xxx)
RewriteCond %{REQUEST_FILENAME} !-d
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{DOCUMENT_ROOT}/landing/$1.html -f
RewriteRule ^(.*)$ landing/$1.html [L]

# 5. Routing Fallback langsung jika file .html ada di root
RewriteCond %{REQUEST_FILENAME} !-d
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME}.html -f
RewriteRule ^(.*)$ $1.html [L]

# 6. Kompresi GZIP & Keamanan Header
<IfModule mod_deflate.c>
  AddOutputFilterByType DEFLATE text/html text/plain text/xml text/css text/javascript application/javascript
</IfModule>

<IfModule mod_headers.c>
  Header set X-Content-Type-Options "nosniff"
  Header set X-Frame-Options "SAMEORIGIN"
  Header set Referrer-Policy "strict-origin-when-cross-origin"
</IfModule>

# 7. Blokir akses ke folder sensitif
RewriteRule ^(docs|@agents|Zzz|\.git|\.rtk)(/|$) - [F,L]
<FilesMatch "\.(md|txt|log|json|env|sql)$">
  Require all denied
</FilesMatch>
<FilesMatch "^(INIT STITCH\.txt|init-stitch\.txt)$">
  Require all denied
</FilesMatch>
```
